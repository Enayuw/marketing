## 完整版

**项目描述**  
面向多家金融与互联网客户的营销数据中台，承接营销人群与转化数据的接入、清洗、批量跑分及结果下发；支持 HTTP、SFTP、RocketMQ 等多种集成方式，并针对携程、同程、58、滴滴等客户提供专线能力。

**技术架构**  
Java 17、Spring Boot 2.7、MyBatis、RocketMQ 5.x、RabbitMQ、Elastic-Job、Redis、Elasticsearch、Aviator 规则引擎、SFTP/gRPC、多模块 Maven 拆分部署。

**职责描述**

· 负责客户侧营销人群与转化数据的 HTTP 接入，设计主/应急/小流量多 Topic 异步落库，保障高峰削峰与幂等。  
· 参与跑分任务全链路：任务生成、Elastic-Job 调度执行、结果校验及跑分暂停/恢复与告警。  
· 实现可配置数据清洗：原始数据分页、规则引擎处理、回写上传主表并支持试跑与正式环境隔离。  
· 负责 SFTP 文件入库、转化文件生成及离线跑分结果分片合并推送客户 FTP。  
· 维护对内运营 API：客户与跑分规则、推送过滤、同步报表、数据清洗与权限配置。  
· 对接电销/决策等下游：RocketMQ 出站消费、规则调度周期推送及推送状态查询。  
· 参与携程/同程/AI 等甲方定制模块：撞库 Job、多 Topic 报表消费、延迟补偿队列。  
· 完善链路重试、过期监控、自动对账与 Prometheus 埋点，提升长链路稳定性。
